## How the evidence was produced

- The exporter and repair tools were run from the repository root with
  `00_orchestrator/runtime.sh` resolving the shared package trees.
- Every repair was validated with page count, PDF syntax and rendered pixel
  comparison before atomic publication; the previous export was preserved.
- OCR validation compared rendered pages before/after and required zero visual
  changes plus no lost text.
- The browser QA used Playwright at 1440×900 and recorded console/page/HTTP
  errors.
- The test counts in this repository come from the local runner on 2026-11-13:
  162 app + 53 pipeline + 12 OCR + 3 guest-setup = **230**.

Detailed evidence remains on the source machine because it can identify the
private corpus. The public summary intentionally contains aggregate metrics
only. Generate new local reports after restoring assets; do not commit them.
